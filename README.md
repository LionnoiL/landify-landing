## 🚀 Технологічний стек

- **HTML5** — семантична та доступна розмітка.
- **SCSS (Sass)** — використання препроцесора для створення гнучкої та модульної
  архітектури стилів. **Це мій перший навчальний проєкт із використанням SCSS**,
  де були відпрацьовані наступні можливості:
  - Вкладені селектори (Nesting) для кращої читаємості коду.
  - Змінні (`$variables`) для керування колірною палітрою, шрифтами та
    відступами.
  - Міксини (`@mixin` та `@include`) для повторного використання блоків коду та
    зручного керування медіа-запитами.
  - Розділення стилів на окремі логічні модулі (файли `_*.scss`) та їх імпорт
    через `@use`.
- **CSS3 / БЕМ** — методологія Блок, Елемент, Модифікатор для чіткої структури
  класів та Flexbox/Grid для побудови сіток.
- **SVG** — використання векторної графіки для іконок, кастомних підкреслень та
  фонових фігур без втрати якості.

## 📱 Адаптивність

Верстка проєкту виконана з використанням підходу **Mobile First** (від мобільних
пристроїв до десктопу):

- Базові стилі написані під мінімальну ширину екрана (мобільні пристрої).
- За допомогою SCSS міксинів та медіа-запитів `(min-width: ...)` інтерфейс
  плавно адаптується під планшети та десктопні монітори.
